# Security Policy

## Supported Versions

The following versions are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please report it responsibly:

1. Open a private security advisory through the GitHub repository's **Security** tab.
2. Alternatively, reach out via GitHub to [@DyharL](https://github.com/DyharL).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.

Security reports will be acknowledged within 48 hours, and validated fixes will be tagged and released promptly.
